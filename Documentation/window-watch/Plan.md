# Plan - Window Watch

## Goal

Ship a free offline window watch for kids, families, and seniors. Six spots stay on the phone. Each spot is a bird, a cloud, or a car. The huge line names the last thing seen.

## Approach

1. App Store Connect has no rejected version waiting.
2. Build Window Watch in Expo: one screen, six spots, and a saved watch.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## Result

Build 1 is Waiting for Review. Submission `de105fb3-2321-444b-951f-d4bddeb980ef`. App Store id `6818780494`.

## Why this app

Turn timers, picture lists, outing plans, dice, dinner answers, household places, tapped sentences, copy-the-line, room hunts, shape pairs, two-person poses, a week of walks, dressing choices, and a shared orange are already in this pipeline. Leave-home checklists already fill the store. This one does not use a clock, a camera, or a network. The family looks out a real window and the phone keeps what they saw.
